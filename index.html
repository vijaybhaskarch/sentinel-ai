What does the IDS look for?

3 easy warning signs

The IDS watches data moving on the network and spots bad behavior.

🔔

Too many knocks

One source sends thousands of connection requests every second.

= Flood attack (DDoS)

Like ringing a doorbell 1,000 times so the owner cannot get out.

🔑

Too many wrong passwords

Hundreds of failed logins in one second.

= Password guessing (Brute force)

Like trying 50 keys on one lock.

💉

Trick commands

Database commands hidden inside a normal web form.

= SQL injection

Like writing a secret order on a food order slip.

In simple words: the IDS knows what bad behavior looks like. When it sees it, it raises an alert.

It also checks for hidden attacker code and requests to a secret cloud-key address. Numbers in the demo are examples.

How does it decide?

3 simple checks

📃

1. Known bad patterns

Like a wanted-poster list. If the traffic matches a known attack pattern, raise an alert.

⚡

2. Too much, too fast

Count requests per second. If the number is far above normal, something is wrong.

🌡️

3. Danger score

Give a score from 0 to 100. Then label it Low, Medium, High or Critical.

In simple words: match the pattern, check the speed, give a danger level.
What attacks can it find?

6 common attacks

🌊

Flood (DDoS)

Too many requests, so the website crashes.

💉

SQL injection

Tricking the database with hidden commands.

☠️

Remote code attack

An unknown weakness lets the attacker run their own code.

🔑

Credential stuffing

Trying leaked passwords on many accounts.

🔒

Ransomware signal

An infected computer calls its boss to lock your files.

🖥️

Password guessing (SSH)

Ask AI button

A helper that explains and advises

💬

1. Explains

Tells you in plain words what the attack is and why it is dangerous.

🏷️

2. Names it

Gives the official attack ID from MITRE ATT&CK, a worldwide dictionary of attack names.

📋

3. Gives a fix

Shows a ready-made firewall rule. Press Copy and use it.

In simple words: an assistant that tells the analyst what happened and what to do next. Example: SYN flood = T1498, SQL injection = T1190.

It follows fixed rules, so its answers are fast and easy to explain.
